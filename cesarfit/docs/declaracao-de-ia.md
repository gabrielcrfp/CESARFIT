# Declaracao de uso de IA

Este projeto **utilizou** assistentes de IA generativa. Conforme o requisito da
disciplina, as interacoes devem ser entregues junto com o codigo.

## Como usamos

| Uso | Onde | Responsavel pela revisao |
|---|---|---|
| Estruturacao inicial do projeto e da arquitetura | esqueleto de pastas, `pom.xml` | (nome do integrante) |
| Sugestao de nomes da linguagem onipresente | `docs/linguagem-onipresente.md` | (nome do integrante) |
| Rascunho dos cenarios BDD | `src/test/resources/features/*.feature` | (nome do integrante) |
| Revisao de codigo e refatoracao | pacotes `domain` e `application` | (nome do integrante) |

## Registro das interacoes

Exportar cada conversa (PDF ou Markdown) para `docs/interacoes-ia/` seguindo o padrao
`AAAA-MM-DD-assunto.md`. Todo codigo gerado por IA foi lido, ajustado e testado pela
equipe antes do commit.

> Caso o grupo opte por **nao** usar IA, substituir este arquivo pelo texto:
> "Declaramos que nenhum artefato deste projeto foi produzido com auxilio de
> ferramentas de inteligencia artificial generativa." com a assinatura dos integrantes.
